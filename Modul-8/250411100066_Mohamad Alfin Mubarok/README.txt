TP8 PAW - MODUL 8 : SESSION DAN SECURITY (PHP + MySQL)
1. Jalankan Laragon/XAMPP (Apache + MySQL).
2. phpMyAdmin > Import > database.sql (membuat database "penjualan", tabel, dan data).
3. Salin folder ini ke www/htdocs, buka http://localhost/tp8_paw/
4. Ubah nama database / user / password MySQL di config.php bila perlu.

Akun login:
  Owner (level 1) : owner / owner123  atau  admin / admin123
  Kasir (level 2) : kasir / kasir123  atau  kasir1 / kasir123
  Level 3 (gudang1 / gudang123) ditolak login karena hanya level 1 dan 2 yang boleh masuk.
