TP6 PAW - MODUL 6 : MASTER DETIL (PHP + MySQL)
1. Jalankan Laragon/XAMPP (Apache + MySQL).
2. phpMyAdmin > Import > database.sql (membuat database "penjualan" + data).
3. Salin folder ke www/htdocs, buka http://localhost/<nama_folder>/
Halaman: transaksi.php (master-detail), barang.php (hapus barang + pengecekan).
Ubah user/password MySQL di config.php bila perlu.
