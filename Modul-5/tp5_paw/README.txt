TP5 PAW - MODULE 5 : DATABASE (PHP + MySQL)
1. Jalankan XAMPP/Laragon (Apache + MySQL).
2. Buka phpMyAdmin > Import > pilih database.sql (otomatis membuat database "penjualan" + data min. 10 per tabel).
3. Salin folder ini ke htdocs (mis. htdocs/tp5_paw) lalu buka http://localhost/tp5_paw/
4. Jika user/password MySQL berbeda, ubah di config.php.
